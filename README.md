# Dashboard Simples (React + Vite)

Projeto de dashboard com tabela editável em memória (`useState`) contendo:

- **Lista** (input texto)
- **Data** (input date)
- **Status** (select: Executado, Em andamento, Pendente)
- Botões de **Adicionar linha** e **Excluir** por linha

## Como rodar

1. Instale as dependências:

```bash
npm install
```

2. Rode em modo desenvolvimento:

```bash
npm run dev
```

3. Abra o endereço exibido no terminal (normalmente `http://localhost:5173`).

## Scripts

- `npm run dev`: inicia servidor de desenvolvimento
- `npm run build`: gera build de produção
- `npm run preview`: visualiza build de produção localmente
